# Gemini 价格行为策略回测：首批 50 次

本记录来自冻结实验 `gemini-year-research-v33-main15-entry5-2000-20261008`。策略周期为 15 分钟，5 分钟用于入场确认，1 小时和 4 小时作为背景，每 15 分钟扫描一次；每笔目标名义金额为 2000 USDT。

本次只完成 576 次优化扫描计划中的首批 50 次：47 次完成、3 次报错。有效决策为 46 次 WAIT、1 次 OPEN_LONG；另有 3 次 Gemini 传输超时。系统接受了 1 笔模拟入场委托，但没有成交，也没有完整平仓。因此这批数据的胜率是**未定义**，不能记成 0% 或 100%，也不能作为 60% 盈利验收。三次超时的根因尚未查明。

部分账本检查通过，固定 2000 USDT 名义金额与交易所数量精度取整检查对 1 笔模拟委托通过；首 50 次执行协议审计因 3 次错误未通过。没有私有交易所调用，也没有 Gate 成交证据。

`model-responses/` 保存 48 份实际记录的 Gemini JSON 回复，保留回复字节并以 SHA-256 对照本机导出。提示词、账户上下文、SQLite、订单标识、请求回执和本地传输错误原文没有放入公开包。

- `summary.json`：回测范围与验收结果
- `index.json`：按扫描序号映射回复文件与有效动作
- `model-responses/`：Gemini JSON 输出

本包是部分历史研究记录，不是全年回测、实盘收益或盈利保证。
