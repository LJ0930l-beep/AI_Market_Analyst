## 本轮实现

1. 宏观日历接入固定的公共周历 JSON，提供来源、更新时间、前值和预期；支持显式刷新、缓存、冷却和失败保留旧数据。自动数据补全沿用现有启用设置。只替换本来源记录，保留手动导入。
2. AI 控制台与做单分析共享账户选择；分析页可见时按请求完成后 3 秒轮询，忽略过期响应并校验账户范围。执行记录读取统一账本，不复制订单、不重放成交；策略驱动与 AI 自主驱动保留独立归因。
3. 默认语言改为中文；补齐交易控制台、授权、分析、宏观日历的显示词汇和状态，Windows 托盘、通知、安装器中文化。用户此前明确保存的英文偏好仍保留，可切回中文；原始证据、协议字段、标的和记录 ID 不改写。模型提示要求面向用户的解释使用中文，不能保证外部原始内容或模型每次输出均无英文。
4. 删除交易风格分析中硬编码的纪律评分、虚构杠杆和固定策略分布；缺乏证据时明确显示未知，不再生成虚假的优秀评价。
5. 保留此前 v1.6 的事件时间、入场后极值、断流保护和完整生命周期归因修复，并纳入回归测试。
6. 修正 Tauri 构建钩子的路径和脚本编码，确保重新生成后端，而不是把旧后端带入新安装包；构建清理仅限已验证的生成目录。

## 数据真实性和安全边界

公共来源：[Forex Factory 周历](https://www.forexfactory.com/calendar?week=this)，JSON 为 `https://nfs.faireconomy.media/ff_calendar_thisweek.json`。

这是第三方日程来源，不是已核验的官方经济数据接口。本次真实请求得到 17 条中高影响事件，状态为 `SCHEDULE_ONLY`。该导出不提供实际公布值，系统保留为空并显示“此源不提供”；不会拿预期冒充实际，也不把已过发布时间当作实际值已确认。严格依赖实际值的风控仍可能拦截，需要具备实际值的可信来源后才能满足该条件。

本轮没有启用真实交易、修改用户的宏观未知放行设置、访问私有交易接口或重启用户策略。自动回归中的宏观未知放行仅用于隔离的模拟测试账户。
