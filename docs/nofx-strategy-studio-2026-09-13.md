参考版本：NoFxAiOS/nofx，dev，`638d4042118995fbf1a38d3822b1139aa3c6b467`。本地只读参考位于 `build/nofx-reference`，未执行它的安装脚本。

## 阅读范围与采用方式

- `store/strategy.go`：策略配置、风险配置及边界校验。
- `web/src/pages/StrategyStudioPage.tsx`、`web/src/types/strategy.ts`：模板、标的范围、指标和资金参数的组织。
- `trader/auto_trader_orders.go`：获取当前持仓和余额、核对保护价格、调整仓位、提交并记录订单。
- `trader/auto_trader_risk.go`：名义仓位 / 权益比例、保证金分配、杠杆与持仓数量限制。
- `docs/architecture/STRATEGY_MODULE.md`：数据装配、策略指令、模型决策与代码风控之间的接口。

上游当前还包含 Claw402 / Vergex 数据源与相关启动流程。这里保留本项目的本地推理服务、公开新闻、Gate 行情及独立执行网关，移植策略配置、指令驱动决策、预算装配和审计分层；NOFX 的 Go 执行器没有并入，避免形成第二条可重复下单的执行链。参考仓库标注 AGPL-3.0。

本机 `GET http://127.0.0.1:8080/v1/models` 的当前清单核验到 `Ternary-Bonsai-2-27B-PTQ1_0.gguf`，运行上下文为 8,192 token；这台机器当前并未实际运行 Qwen3.5-9B。交易前的模型健康检查读取运行清单中的真实身份和上下文，不用配置名称或训练上下文冒充运行状态。

## 本项目可执行配置

策略版本同时保存交易指令与结构化执行配置：

| 配置 | 执行行为 |
| --- | --- |
| 标的与方向 | 仅允许指定币种和做多 / 做空方向新增仓位 |
| 按止损风险计算 | 权益 × 风险比例，除以每张合约的含成本止损损失 |
| 固定 USDT 金额 | 目标为设定的名义仓位；风险或资金不足时向下缩小 |
| 权益比例 | 名义仓位目标 = 账户权益 × 指定比例 |
| 杠杆 | 当前版本允许配置 1–100 倍，执行仍受合约实际能力约束；不增加允许的止损损失 |
| 单笔金额上限 | 三种仓位模式共同遵守 |
| 保证金占用上限 | 扣除已占用保证金，并与实际可用保证金取较小值 |
| 最大持仓数量 | 包含当前持仓与待成交入场单，保护单不占新增仓位名额 |
| 重入冷却 | 同账户、同币种最近入场意图后的冷却时间 |
| 最低置信分数 / 净盈亏比 | 模型外校验，置信分数不代表胜率 |
| 订单偏好 | 自动 / 限价 / 市价；仍须通过实时价格、盘口和成本检查 |

默认单笔风险上限 0.25%、默认杠杆 3 倍；已保存的账户金额与杠杆设置不会被加载模板覆盖。组合风险与日亏损限制继续由独立风险引擎执行。编辑指令不能覆盖硬约束。

## 分析到执行

1. 同步 TestNet 私有账户事实与公开行情、新闻。
2. 冻结账户策略版本及输入证据，交给经运行清单核验的本地模型生成 JSON。
3. WAIT / HOLD 保存分析与未来条件，不生成挂单。
4. 对执行动作再次同步账户与报价，保留分析输入和执行复核两份证据。
5. 按策略、止损风险、名义金额与保证金取最小预算；按合约数量精度向下取整。
6. 统一网关复核、发单及管理保护；决策记录保存实际金额、杠杆、保证金估算、止损风险及限制来源。

配置试算使用最近取得的 TestNet 账户权益和用户假设的止损距离，未计费用 / 滑点；它不是交易指令。实际下单会重新计算。

## 同时修复的数据读取问题

`latest_bars` 原先在历史记录升序截断之后才取末尾，记录增长后会反复读到旧数据。现在先在每个完整行情标识内选定最新版本，再按最近时间取样；已收盘记录不会被晚到的未收盘更新降级。AI 技术面明确使用 Gate 永续合约的 last 价格，避免混入 mark / index 与旧版镜像。

## 验证边界

测试覆盖账户隔离与版本冲突、资金模式和硬上限、杠杆不放大风险、实际引擎的金额落库、模型分析后的报价变化、超过 2,000 条历史记录的最新 K 线读取。真实 TestNet 决策证据单独保存；模型返回 WAIT 不能充当入场成交验收或收益表现证明。

## 9 月 13 日追加：四策略、全品种与确定周期

| 模板 | 风格 | 扫描周期 | 输入周期 |
| --- | --- | --- | --- |
| 事件脉冲 | 激进 | 5 分钟 | 5m / 15m / 1h |
| 趋势突破 | 激进 | 15 分钟 | 15m / 1h |
| 共振回踩 | 保守 | 15 分钟 | 15m / 1h |
| 宏观防守 | 保守 | 15 分钟 | 15m / 1h |

单账户启用一个策略版本，继续采用一条 AI 决策路线。模板保存会同步结构化 `scan_interval_minutes`；文字提示不能改变实际调度。开始、恢复、保存策略均等待下一次整点边界，不再立即补一轮。`ai_schedule_slots` 以账户 + 计划时间唯一约束，防止重启或周期切换重复触发。错过周期不回放，正在分析时不会并发启动另一轮。时间线统一香港时间，并区分计划时间、开始时间和模型完成时间。

交易范围从当前账户环境的 Gate 合约 API 动态获取；本次 TestNet 实测发现 63 个合约。范围为本项目执行器支持的 USDT 永续合约，TestNet 上未提供的主网合约不会伪装成可执行。默认全品种，也可搜索并自选。每轮读取全市场 ticker：已有持仓优先，其余按照成交量领头品种及时间轮换候选，最多 5 个进入本地模型分析；这只是输入预算分配，不是机械开仓信号。无报价、无成交量或已下架标的不新增风险。

新增品种通过真实合约元数据注册，新闻刷新复用该注册信息。分析路线直接更新所需已收盘 K 线，不再为每个轮换标的执行传统策略的 600 根回测初始化。指标仍由有效历史计算，模型接收当前信号周期最近 3 根 K 线、其它周期指标摘要及每个标的最多一个候选；完整证据留在本地。若 48 小时内没有适用新闻，模型必须明确标注新闻未知；新闻缺失本身不阻断有充分技术证据且通过风控的交易。

界面加入轻量 CSS 粒子、轨道背景、模板悬停、导航和状态过渡。页面隐藏时停止背景动画，支持系统减少动态效果设置，右上角提供动效开关。没有引入动画依赖或远程素材。

Gate 环境与端点依据：[官方 API v4 文档](https://www.gate.com/docs/developers/apiv4/en/)。
