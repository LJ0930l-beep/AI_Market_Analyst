# AI Market Analyst V1.1 user guide

## First preparation

1. Install Python, Node/npm and official Ollama.
2. Install project dependencies once as described in the README.
3. Double-click `Prepare_AI_Models.cmd`. It downloads exact official tags `qwen3.5:4b` and `qwen3.5:9b` only when missing.

## Daily use

Double-click `Start_AI_Market_Analyst.cmd`. Wait for the Chinese ready message and the browser opens at `http://127.0.0.1:4173`. Repeating Start does not create duplicate API/UI processes. Use `Status_AI_Market_Analyst.cmd` to inspect and `Stop_AI_Market_Analyst.cmd` to stop only this project's recorded children.

Choose 中文 or English in the header. Settings controls UI language, AI response language, local notification language and Fast/Smart/Auto model preference.

Dashboard summarizes only saved evidence. `unavailable` means there is no defensible point-in-time value; `stale` means evidence exists but is old. Calendar, News and Heatmap follow the same rule. Generate Daily Brief only when you want an explicit Smart/selected model artifact.

AI Assistant is research help, not investment advice. Select an optional supported symbol or enter from Asset Detail/Signals. Stop cancels the current generation; Clear removes only this browser tab's conversation. Chat is not part of SQLite backups.

Analysis remains explicit and always saves a Prediction, including WAIT. Follow is the only way to create a local PaperTrade. Nothing in V1.1 places a real order or connects a broker.

## Troubleshooting

- Model unavailable: run `Prepare_AI_Models.cmd`, then check Ollama and `/health/model`.
- Port occupied: do not kill by port/process name; use this project's Stop command or change ports through the advanced launcher.
- Launcher ownership mismatch: inspect the reported state/log path. It refuses to stop a process when fingerprints differ.
- Restore: stop the launcher and all DB connections first; the accepted backup tool refuses WAL/SHM sidecars.
