# V1.1 AI Assistant upgrade

AI Assistant builds on the accepted local NDJSON streaming consultation and upgrades the contract to `qwen_consult_v2`. It supports multi-turn session-only history, incremental rendering, AbortController stop, explicit clear, Enter send, Shift+Enter newline, optional registered symbol context and exact Prediction handoff from Signals.

The server accepts only bounded user/assistant history, language, allowlisted preference/task values, symbol and Prediction ID. It constructs the system prompt and evidence envelope, selects a configured local model, enforces serial concurrency/time/body/history/output limits and emits sanitized structured errors. It never logs or persists the complete chat, accepts a client model/base URL, fabricates fallback text or performs analysis, scan, settlement, Follow, broker or ledger writes.

Context is saved evidence with as-of, provenance, freshness and missing reasons. A Prediction handoff must match the selected symbol. The model may interpret this context but cannot calculate or override Python financial/time/risk rules.
