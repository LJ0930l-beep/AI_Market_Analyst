# AI Market Analyst V1.1 completion report

Status: developer implementation complete; supervisor Gate pending. Version `1.1.0`, API phase 7, SQLite schema 11. This report does not alter the accepted V1.0 Final Acceptance record.

## Delivered scope

V1.1 turns the existing local research ledger into a bilingual, high-density financial terminal. The primary navigation is Dashboard, Signals, Watchlist, Markets, Calendar, News, Heatmap, AI Assistant, Replay/Backtest, Performance and Settings. Accepted PaperTrade and Alert Center routes remain available through contextual links without changing Follow or local-alert semantics.

The read-only `market_intelligence_v1` aggregate uses durable Watchlist, latest saved Predictions and point-in-time stored event/news evidence. Market Pulse covers BTC, ETH, NVDA, NASDAQ, VIX and US10Y but returns `unavailable` or `stale` when saved proof is absent. Calendar, Watchlist monitoring, Heatmap and news similarly expose capability/missing evidence and never substitute fixture values for live data. `daily_brief_v1` is generated only by an explicit user POST, records as-of/source hash/missing evidence/model tier/route reason and does not create a Prediction, Outcome, PaperTrade, alert, scan or calibration change.

`qwen_consult_v2` adds deterministic `qwen_route_v1`: Fast=`qwen3.5:4b`, Smart=`qwen3.5:9b`. Fast is the default for frequent/simple tasks; Smart serves Assistant, signal explanation, Daily Brief, event analysis and deep research. Fast/Smart/Auto is a server-owned route decision; the client cannot submit an arbitrary model or URL. Conversation remains NDJSON-streamed, cancellable and browser-session-only.

## Reference-to-system translation

The supplied Dashboard reference was treated as information-architecture and visual-direction evidence, not as a pixel or data source. Its deep navy shell became centralized terminal tokens (`canvas`, raised surfaces, rules, semantic opportunity/risk/event/AI colors), a fixed icon-plus-bilingual desktop rail, a horizontal evidence ticker, a dense three-column module grid, confidence ring, monitoring cards, point-in-time event/news lists, evidence heatmap and full-width brief/regime ribbon. No brand detail or displayed number was copied. The captured Dashboard therefore shows saved fixture evidence and explicit unavailable/stale states rather than invented live quotes.

Desktop-first layout is bounded at 1440/1280 widths and collapses to one column at 390px. Focus styles, semantic regions/tables/lists, keyboard-scrollable wide tables, reduced-motion support and deep-theme contrast are included. The real-browser Gate scans every product route at desktop and 390x844 with axe and page-level overflow checks.

## Internationalization and settings

The dependency-free typed catalog has exact `en`/`zh-CN` parity and render-time fallback. All 14 route trees and nested Health/Provider/count/scheduler/research/chart components use explicit typed keys for fixed copy, navigation, controls, errors, empty/loading/degraded states, facts, badges and accessibility labels; product routes do not depend on heuristic `LocalizedSurface` traversal. Standard enums are localized only in the display layer. Symbols, URLs, API/model identifiers and backend free text remain unchanged, while Intl formats dates, numbers and percentages using the selected locale.

Durable allowlisted settings add UI Language, AI Response Language, Notification Language and Model Preference. UI language also remains in browser localStorage for immediate startup selection; AI and notification preferences are stored as typed JSON settings. No preference activates the scheduler or background work.

## Safety and compatibility

Python still owns technical indicators, prices, risk, time/session rules, deterministic scoring, settlement and evidence selection. Explicit analysis always saves a Prediction, including WAIT. Only Follow creates an idempotent PaperTrade. V1.1 adds no broker, order, private key, cloud service, external notifier, Redis/Celery, telemetry or model-authored financial calculation. GET intelligence, health and consultation context reads are side-effect safe. Startup is idempotent, scheduler remains default-off and Qwen is never invoked at startup.

## Honest limitations

Market Pulse/Calendar/News/Heatmap are only as complete as saved point-in-time evidence; no always-on macro, on-chain, ETF, funding, OI or sector feed was invented. Equity session policy still lacks a complete exchange-holiday calendar. Auto routing is deterministic and does not silently fall back when its selected model is unavailable. The first cold 4B attempt exceeded the former 20-second first-token bound; V1.1 therefore uses a still-bounded 60-second first-token allowance for local model swapping. Model quality/latency depends on local Ollama, GPU memory and concurrent workstation load. Deterministic browser fixtures prove contracts, not live provider or model quality, and the two real prompts do not establish provider freshness or ComfyUI coexistence performance.

Verdict: the consolidated internationalization repair is developer-ready pending the supervisor's independent V1.1 Gate rerun; acceptance is not claimed here.
