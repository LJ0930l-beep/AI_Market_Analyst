# AI Market Analyst V1.2.1 User Guide

## Install and launch

Run `AI Market Analyst_1.2.1_x64-setup.exe`. The application installs for the current user under `%LOCALAPPDATA%\Programs\AI Market Analyst`; durable data, logs, backups and runtime records remain under `%LOCALAPPDATA%\AI Market Analyst`. Start it from the Start menu or run `ai-market-analyst.exe`. Production does not need Node.js, npm or Vite.

The desktop starts only its packaged loopback backend. It normally tries ports `18765..18828` and skips any port already owned by another process. A second launch focuses the existing instance.

## Start Smart Monitoring

Monitoring never starts merely because the app launched.

1. Open Monitoring.
2. Enable only the BTCUSDT, ETHUSDT or SOLUSDT policies you want and save them.
3. Select Start monitoring. Status changes to starting/running after the sidecar worker begins its public REST/WS cycle.
4. Use Pause to stop work temporarily, Resume to continue, or Stop to terminate work and clear resume eligibility.

Run now executes one explicit cycle and is not the background worker. Smart analysis is invoked only when Python's `trigger_policy_v2` identifies a new state on an exactly-once closed 15m bar. Smart requires local `qwen3.5:9b` and never silently substitutes 4B.

## Tray and closing

The tray menu shows current Monitoring state and provides Open terminal, Pause/Resume, Settings, Restart backend and Exit. If Monitoring is active, window X always hides the window and explains that monitoring continues. Reopen from the existing app/tray. If Monitoring is inactive, X follows Close to tray; when that preference is off it exits. Tray Exit is always an explicit full exit and stops only the owned sidecar.

## Startup preferences

Auto Start uses the Windows current-user login registration. It is off by default and starts only the app/tray. Resume Monitoring on Startup is separate, also off by default, and does not authorize a policy that was never explicitly enabled. Keep both off if you want every monitoring session to start manually.

If the backend is degraded, Settings and the tray expose Restart owned backend. The action never restarts or stops Ollama, ComfyUI or another application. A foreign process occupying 18765 is not killed; the app selects another allowed loopback port.

## Charts, alerts and news

Asset pages show app-supplied 15m/1h Lightweight Charts plus Python-owned overlays. TradingView is not used as a market-data API. Alert Center stores deduped local alerts. Native Windows notification permission is optional; denial only degrades to the in-app banner/Alert Center route.

English news retains source, original title/summary and structured values. Explicit Chinese translation uses the local 4B model and is cached only after numeric/date guard validation.

## Models

Install the exact local models with:

```powershell
ollama pull qwen3.5:4b
ollama pull qwen3.5:9b
```

Ollama is an external local dependency. The app does not start, stop or uninstall it.

## Data and uninstall

Uninstall removes the program and autostart entry but deliberately preserves `%LOCALAPPDATA%\AI Market Analyst`. Use the explicit legacy importer for an older repository database; the app never silently replaces the current database. This product is research-only: it has no account, secret, broker, order or funds capability.
