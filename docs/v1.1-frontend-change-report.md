# V1.1 frontend change report

The React application now uses a centralized dark-terminal token layer and an eleven-item product navigation. Dashboard is a three-column evidence deck with Market Pulse, events, monitored Watchlist, latest Signal research memo, sector/asset heatmaps, saved news, explicit Daily Brief and regime/risk/opportunity summary. Markets, Calendar, News and Heatmap are first-class read-only routes with loading, empty, unavailable and point-in-time provenance states.

Signals and Asset Detail link directly to AI Assistant with a validated symbol and, for Signals, exact Prediction ID. Settings persists language and model preferences through typed API values. Existing Watchlist, Replay, Performance, scheduler, alerts and paper-only flows retain their accepted API behavior.

Every fixed string in the 14 route trees, including nested operational facts, scheduler facts, research facts and OHLCV chart states, now resolves through the parity-checked typed `en`/`zh-CN` catalog. Locale-sensitive values use the selected locale; symbols, URLs, model/API identifiers and backend free text remain unmodified.

Responsive behavior uses a fixed desktop rail and dense card grid above 1080px, a reduced grid through tablet widths and one-column content plus compact navigation at 390px. Wide calendar evidence is a labeled keyboard-focusable scroll region. The Gate covers all routes with axe and page overflow checks.

No chart or card claims live data solely because it is visually styled. Missing evidence displays unavailable/stale capability, and backend free text remains intact.
