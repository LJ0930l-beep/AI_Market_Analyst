# V1.1 internationalization implementation

The frontend uses a lightweight typed React context with explicit `en` and `zh-CN` catalogs. `TranslationKey` is derived from the English catalog, while the Chinese catalog is a compile-time `Record<TranslationKey, string>`; parity and fallback are also unit-tested. There is no i18n runtime dependency and no DOM MutationObserver/post-render text scanner.

Initial language comes from `ai-market-analyst.language`, then browser `zh-*`, then English. The global accessible selector persists immediately. Render helpers provide locale-aware `Intl.NumberFormat` and `Intl.DateTimeFormat`. Standard backend enums are mapped only for display; API payloads, SQLite values, symbols, model IDs, URLs and timestamps are never rewritten.

All 14 product routes and their nested components use explicit, typed `t(key)` calls for fixed copy, labels, controls, table headings, facts, errors, empty/loading/degraded states and accessibility text. This includes Health/Provider routing/count/instrument facts, scheduler operations, research facts and OHLCV chart summaries. `LocalizedSurface` remains only as an unused compatibility utility; no product route depends on heuristic recursive text translation. Free provider/model/evidence text, raw JSON and technical contract identifiers are shown as received, while standard enums are mapped explicitly in the display layer.

Number, percentage and date/time formatting always uses the selected locale rather than the runtime default. Focused component tests render Chinese Settings, OperationalFacts/CountLedger and Asset Detail/ResearchFacts/OhlcvChart trees. Browser coverage visits every route in both languages, rejects the known fixed-English leakage set in Chinese mode, verifies refresh persistence, and retains desktop plus 390x844 accessibility/overflow checks.

Settings additionally persists `ai.response_language`, `notifications.language` and `ai.model_preference`. AI output language may follow UI, force Chinese or force English. Notification language affects local Alert Center presentation only; no external notifier exists.
