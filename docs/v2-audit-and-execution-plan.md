# V2 实用化审计与实施基线

日期：2026-09-07。基线：b28cde3；审计开始时工作区干净。本报告基于 V2 设计文档、定向源码检查和一个纯函数复现，不代表全量运行时审计。旧版测试通过不再等同产品实用性通过。

## 已确认问题

1. P0 数据可信度：core/market_intelligence.py 的 _pulse_entry 计算 age_seconds 却沿用缓存 freshness_status。输入 2026-08-01 的行情、fresh 标签、120 秒 TTL，以 2026-09-07 查询，实际输出 available/fresh、age_seconds=3196800。必须在读取时按当前时间重新判断，拒绝未来时间，断网后也必须自动过期。
2. P1 日历语义错误：core/events.py 将 RSS published_at 映射为 event_at；market_intelligence._calendar 无事件类型区分，普通新闻进入财经日历。前值/预期/实际缺少真实结构化供给，不能以列表非空认定财经日历完成。
3. P1 新闻时间窗口和顺序：storage/sqlite.py:list_event_evidence 仅设 as_of 上界，没有 48 小时下界。market_intelligence 先把 calendar 按时间升序，再截取 news[:12]，可能展示候选集内更旧内容。news_engine._parse_date 解析失败回填当前时间，旧内容可能伪装成新内容。
4. P1 涨跌幅口径：market_hydration._save_market 缺失 change_pct 时用上一根 K 线收盘计算；Crypto 使用 15m，股票使用 1d，同一字段语义不一致。必须明确 24h、交易日或周期口径，缺失不能偷换。
5. P1 图形误导：styles.css 的 pulse-card__trace 是旋转边框，不是历史行情曲线。必须替换为真实序列或移除。
6. P1 功能割裂：监控按 monitoring_policies.enabled 订阅 Binance WS，未以用户自选与策略订阅作为统一入口；公开仪表盘补水又有独立固定列表。需区分浏览行情与策略盯盘资源，统一监控生命周期。
7. P1 V2 能力缺失：定向检索未发现 Gate/ccxt、MacroGuard、BaseStrategy、strategy_subscriptions 等目标实现。现有指标与 Qwen 分析不等于插件策略和交易执行闭环。
8. P2 界面：12 个入口、紫色强调、大标语、工程字段、固定分类热力图仍在。按 V2 5+1 入口与交易任务重组。

## 文档不能照搬的部分

- core/quant、core/replay、core/performance 存在真实计算实现；不能把全部代码称为空壳。移除无用入口可以，保留有价值的验证逻辑与历史数据。
- Gate 全资产与测试网能力须通过官方资料和实际 market metadata 验证；不能靠字符串替换假定合约存在。
- 文档先开仓再挂止损不是原子保障。必须设计保护单失败、部分成交、超时重试、幂等、对账和紧急停止；模拟环境验证这些失败路径。
- 文档金融示例是样例，不是实时事实。模型输出提供简明决策依据、来源、时间和反对证据，不以冗长思维链作为可信证明。
- 宏观数据源和规则缺失时明确 unavailable；不得把 RSS 或模型猜测包装成前值/预期/公布值。模型建议要经规则校验、范围/有效期限制。
- 真实资金下单、外部消息发送需要用户明确启用；开发默认模拟。密钥不入源码、日志和前端；不自动使用现有密钥。

## 整批实施顺序

由同一个 Luna 承接整个 V2 里程碑，内部按依赖推进，最终一次回传。先完成剩余定向审计并更新本报告，再实施：
1. 数据可信度：时间、来源、口径、缓存、新闻/宏观分离与故障状态。
2. 统一自选、策略订阅、Gate 公共行情和监控生命周期；平滑数据库迁移。
3. 插件策略、结构化 Proposal、Qwen 决策、确定性风控、模拟执行和可追踪生命周期。
4. 5+1 UI 重塑、实用设置和安装版交付。
5. 真实来源集成与模拟成交端到端验收；一次性汇总缺口，不用 fixture 冒充实机通过。

## 实用性验收

- 新安装无测试数据，无行情时解释原因；分别记录 UI 可交互和首批真实数据耗时，不伪称联网数据必在三秒内齐全。
- 时间推进、断网、重启后旧行情不会保持 fresh；新闻严格 48h 且最新在前；宏观数据可追溯且与新闻分离。
- 添加自选、开启策略、订阅启动、关闭退订、删除自选停止监控形成可观察闭环；无重复 worker。
- 四策略各有正反样例与无前视数据验证；资金费率缺少 OI/历史时不能伪造。
- Proposal 具备入场、止损、分批止盈、方向、期限、策略版本；仓位/费用/滑点/精度在风控和模拟成交中一致。
- Qwen JSON 异常、模型不可用、宏观阻断、超风险、重复触发均不能产生未授权交易；保留决策摘要和执行证据。
- 中文界面主要任务完整可用，真实 K 线可见；首次使用无需开发者代启动。
- 全部适当门禁、安装版截图、升级保留、最终安全状态、已知限制明确记录；未验证项不得写 PASS。
