### A3 信号时效

基线测试先确认两个缺陷：35 分钟前的 failed-breakout 仍会保留为候选；缺少当前报价时，历史 re-entry 收盘价 `104.0` 会被放进 proposal 入场价。另有旧分区标签测试证明 pilot 顺序会造成错误划分。

现在规则 `FAILED_BREAKOUT_20X15M_5M_REENTRY_FRESH_V2` 固定如下：

- 确认时刻：re-entry 5m bar 收盘；信号从该 bar 的 `available_at` 起才可用。
- 最长有效期：600 秒；决策时刻大于或等于到期时刻即过期。
- 失效：后续闭合 5m bar 再次向突破方向收回冻结的 20 根 15m 区间外，或先触及/越过保护止损或区间目标。
- 入场：只接受确认之后、决策之前的点时 best bid/ask；报价距决策不超过 60 秒，必须有效且位于有效交易区间。
- LONG 取 best ask、SHORT 取 best bid。历史 re-entry close 单独存放，不能作为可成交价格；缺失、过期、非因果或无效报价均不进入风险经济计算。

规则 JSON SHA256：`21b62ed5881dd86b7763be59016492008b1080ad787463a7861a204ef288f055`。该规则只授权离线研究，没有生产交易权。
