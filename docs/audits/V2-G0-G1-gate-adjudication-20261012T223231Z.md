## 裁定

选择将“正向远端校准身份模式”的组合断言归入 G4。G0 只要求校准在缺少已验证身份或权重摘要时 fail closed：结果为 `NOT_READY`、模型调用数为 0、且不创建活动校准 profile。G0 不要求实现或验证正向 `REMOTE_WEIGHTS_NOT_EXPOSED` 模式。

G4 的远端身份模式仍须等 G0–G3 前置门禁完成后单独设计、测试和审查。此裁定只消除 G0/G4 的循环依赖，不降低风控、不提前实现 G4、不接受 G0、不授权 G2，也不授权 Gemini、Gate、TestNet 或 Live 请求。

## 选择理由与影响

这项解释遵循阶段顺序：G0 验证当前可执行代码在缺少可信身份资料时安全拒绝；G4 再定义远端模型没有暴露权重时的身份契约。它避免把负向 no-call 测试误报为正向远端身份验证，也避免为了满足 G0 文档而提前跨入 G4。

因此，B-20261013-006 的“书面门禁顺序冲突”已解决；B-20261010-003 仍为 OPEN，因为 G4 的正向模式和完整负向矩阵尚未实现。G0 仍待 PR #26/#27 独立审查及其余验收条件，G2 仍未授权。
